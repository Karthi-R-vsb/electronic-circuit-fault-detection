How it works

  1. Pick a circuit. Choose the circuit you built or are studying from the circuit library.
  2. Enter your readings. Type in what your multimeter or scope actually measured at each test point.
  3. Compare against expected values. Each measurement is checked against the textbook-expected range for that circuit.
  4. Score the likely faults. A rule-based engine matches your symptoms against known fault patterns and ranks the top 3 candidates by confidence.
  5. Read the reasoning. You get possible causes and numbered troubleshooting steps — not just a verdict.

CircuitDX is an educational estimation tool. It cannot physically test a component — treat every result as "most likely," not "confirmed."

About CircuitDX

Purpose

CircuitDX is an educational software tool that helps electronics students understand circuit troubleshooting and identify possible faults using measured electrical values. It was built for coursework in electric circuit analysis and electronics, as a way to practice fault-finding logic without needing a lab bench on hand.

Technologies

HTML5, CSS3, and vanilla JavaScript only. No frameworks, build step, backend, database, or API key — open index.html and it runs.

Advantages

  • Easy to use, no hardware required
  • Instant, offline diagnosis
  • Explains reasoning, not just a verdict
  • Helps build troubleshooting intuition
  • Works on desktop and mobile

Limitations

  • Rule-based estimation, not a physical test
  • Cannot detect faults it has no rule for
  • Confidence scores are symptom-matching scores, not measured probabilities
  • Not a substitute for a multimeter, oscilloscope, or a qualified technician

Future enhancements

AI-assisted diagnosis, real-time sensor input via Arduino/ESP32, oscilloscope waveform analysis, PCB image analysis, a mobile app, and cloud-synced diagnosis history.
